# Five generated game renderers for Lovable

Use `generated-showcase.json` as the portable source of truth. It contains five packs generated by the real assembler, not five skins of one puzzle. Run `node scripts/generate-game-showcase.mjs` to regenerate it.

The categories are binary friend fill, crowns, numbered path cover, pipe rotation and lights cross-toggle. Each game has its own public rules, win predicate, category renderer requirements and seven verified input/output snapshots. The included `files` map contains the exact typed schema, shared action reducer and public verifier, with their required imports. Use Zod 4. Author certificates and answers are excluded.

Keep the two work tracks separate:

- **mini-game-rules:** durable mechanics, schema, public clues, action effects, win predicates, postcard copy and mode. This bundle belongs here.
- **battle-ground-ui:** the frozen hackathon frame. Reuse its white board, OKLCH craft tokens, Human|Agent tabs, dual clocks and demo layout. Add category renderers inside that frame; do not restyle the frame for each game.

Both Human and Learner use the same pack and seed, the same action reducer and the same clock. Wire `selectCell(cell)`, `cycle()`, `undo()` and `clear()` into `applyGameAction`. Use `verifyGame(pack, state.cells)` for completion. Selection plus cycling is the same action sequence for both players. Lock advance until both finish or reach the shared cap. Hints are practice-only.

Most rounds should take roughly 10 seconds to two minutes. The target is an estimate, not a timeout or failure. A stuck player may continue up to the shared ten-minute stretch cap.

The five examples demonstrate five renderer types. They are not one learning-slope cohort. Compare falling actions across at least three respawns within the same rule family and board size. "We score the pattern they carried forward, not the puzzle class they recognised."

The games may resemble Tango, Queens, Zip, pipe toys or Lights Out. That resemblance is acceptable. The numbered path game uses ordinal cell cycling to preserve the shared Action API; show the next value beside the selected cell so cycling is understandable on touch. Pipe masks use N=1, E=2, S=4, W=8. Apply `rotatePorts` before rendering, and let the reducer skip physically identical straight-tile orientations.

After the user approves the playable UI, summarize the repeatable design decisions: how schema fields select a renderer, how clues become visible marks, how action effects receive feedback, how the postcard explains the round, and how a new category plugs into the fixed battle frame. Keep those notes separate from the game records.
