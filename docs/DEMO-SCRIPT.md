# Demo script (60 seconds)

Shoot the Human|Agent frame from the Cursor UI port. Lead with the backup MVP. A novel minigame is the last beat, and only if that board is already on screen.

Spoken copy is about 145 words. Read it once against a timer before recording. Cut any beat that is not actually visible.

## Spoken

We score the pattern carried forward, not the class recognised.

One board. I pick the Learner model for this round: GPT-6 Astra, or another OpenAI model the credit allows. My attempt stays on the same pack and the same seed.

Human tab. I select a cell and cycle. Undo and clear are the same buttons the Learner gets. Every tap counts. The clock keeps running while either of us thinks.

Agent tab. This is the Learner’s own attempt, not a copy of mine. It sees the postcard and the visible cells. It can leave one line: a local friend-pattern.

The next seed stays locked until both attempts finish or hit the cap.

If a second mechanic is already up, it uses this same frame. If it is not, this round is the demo.

Public repo: github.com/ghcpuman902/astra-vs-human.

## On-screen beats

| Time | On screen | Say |
| --- | --- | --- |
| 0:00–0:08 | Title card or README line: “score the pattern carried forward, not the class recognised.” Public repo URL in the corner. | Opening sentence. |
| 0:08–0:18 | Model control on the Agent side, set to `gpt-6-astra` (or the chosen id). Seed value visible and unchanged. | Pick the model. Same pack, same seed. |
| 0:18–0:32 | Human tab. One tap: select, then cycle. Action counter increments. Clock moving. Postcard visible. | Human controls and the shared clock. |
| 0:32–0:46 | Agent tab. Learner board diverges from the human board. One-line pattern claim appears. Hint control absent or disabled. | Independent attempt and the claim. |
| 0:46–0:52 | Advance / next-round control still locked while one side is playing, or both counters shown as finished. | Lock until both finish or hit the cap. |
| 0:52–1:00 | Stay on this board. If a novel category (crowns, path, pipes, or lights) is already rendered in the same frame, cut to it for two seconds, then back to the repo URL. | Closing line and the GitHub URL. |

## Backup path

Film beats 0:00–0:52 even when the five category renderers are unfinished. The submission shot is: model choice, one shared pack and seed, two independent attempts, one pattern claim.

Skip the novel-minigame cut if that renderer is a blank, a stub, or a recolour of the binary board.

## Keep out of frame

API keys, `.env.local`, provider error bodies, solution traces, and author footholds. The Learner panel shows the same postcard and visible cells as the human.
